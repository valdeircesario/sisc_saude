# Arquitetura do Sistema

O Sisc Saúde utiliza uma arquitetura desacoplada **Single Page Application (SPA)** no frontend comunicando-se com uma **REST API** no backend.

## Stack
- **Frontend:** React, TypeScript, Vite, TailwindCSS, React Query, React Router Dom.
- **Backend:** Node.js, Express, Prisma, PostgreSQL.

## Estrutura
- **`src/`:** Aplicação frontend.
- **`server/`:** API REST backend.
