# Frontend

O frontend segue a filosofia de componentes atômicos e separação de lógica via hooks e contextos.

## Estrutura
- **`components/`:** UI modular.
- **`contexts/`:** Estado global (ex: `AuthContext`).
- **`hooks/`:** Lógica de negócio e consumo de API (ex: `useNotificacoes`).
- **`pages/`:** Telas e dashboards.
- **`services/`:** Configuração do Axios/API.
