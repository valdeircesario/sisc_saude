# Roadmap

1. **Produção:** Configuração estrita de CORS e HTTPS.
2. **Auditoria:** Implementação de logs detalhados para ações críticas.
3. **Testes:** Criação de testes unitários e de integração (especialmente para validações de dispensação).
4. **Resiliência:** Refatoração do Rate Limiter para diferenciar ambientes.
